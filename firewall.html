Firewall vs Antivirus

Keduanya beroperasi pada perimeter pertahanan yang sama sekali berbeda:

Firewall (Network Layer) Gerbang Luar

Menginspeksi metadata lalu lintas (IP, Port, TCP flags) sebelum paket menyentuh memori atau aplikasi host.

Antivirus (Endpoint Layer) Polisi Internal

Memindai tanda tangan malware (hash), heuristik file biner, dan proses memori saat berkas dieksekusi di disk/RAM.

L3 / L4 Stateless

Packet Filtering (Stateless)

Memeriksa paket satu per satu secara statis tanpa mengingat riwayat sesi sebelumnya.

add_circle Sangat cepat & hemat CPU/RAM.
remove_circle Rentan IP Spoofing & manipulasi TCP flag.
Contoh: Cisco ACL, Router Hardware
account_tree
State Table

Stateful Inspection Firewall

Melacak status sesi 3-way handshake TCP (SYN, SYN-ACK, ACK) dalam tabel conntrack.

add_circle Paket balasan diizinkan otomatis (ESTABLISHED).
remove_circle Dapat menjadi target State Exhaustion / SYN Flood.
Contoh: Linux Netfilter, pfSense, Cisco ASA
sync_alt
Layer 7 Gateway

Proxy Firewall (ALG)

Perantara mutlak. Client tidak pernah terhubung langsung ke server; proxy merakit ulang koneksi baru.

add_circle Isolasi total topologi internal & inspeksi URL.
remove_circle Latensi lebih tinggi karena overhead re-assembling.
Contoh: Squid Proxy, BlueCoat ProxySG
radar
DPI + App Aware

Next-Generation Firewall

Deep Packet Inspection (DPI) terintegrasi dengan Intrusion Prevention System (IPS) dan inspeksi SSL/TLS.

add_circle Membedakan browsing 443 vs Torrent pada port 443.
remove_circle Biaya lisensi enterprise tinggi & komputasi berat.
Contoh: Palo Alto Networks, Fortinet FortiGate

Web Application Firewall

Dikhususkan untuk melindungi protokol HTTP/HTTPS dari SQL Injection, Cross-Site Scripting (XSS), dan RCE.

add_circle Memahami payload JSON, URI request & Cookie.
remove_circle Hanya untuk web; tidak memproteksi SSH/FTP/DNS.
Contoh: Cloudflare WAF, ModSecurity, AWS WAF

Arsitektur Segmentasi Perimeter DMZ

04 // NETWORK DESIGN
public INTERNET (UNTRUSTED ZONE)
Jaringan luar tanpa kendali keamanan; sumber potensi exploit
security PERIMETER FIREWALL (HARDWARE NGFW)

Sentral filter inspeksi paket Stateful & DPI. Mengarahkan jalur sesuai tingkat kepercayaan zonasi.

SEMI-TRUSTED hub

Zona DMZ (Demilitarized Zone)

Subnet khusus publik yang menampung server publik seperti Web (80/443) dan Mail (SMTP 25).

ATURAN EMAS: DMZ Dilarang menginisiasi koneksi ke Trusted LAN!
Aset: [Nginx Web Cluster] + [Postfix Mail]
TRUSTED ZONE admin_panel_settings

Zona Internal (Trusted LAN)

Workstation staf kampus/kantor dan Core Database (Postgres / MySQL) yang menyimpan rekaman sensitif.

AKSES: Hanya lewat Internal Switch atau VPN Terotentikasi 2FA
Aset: [Database Port 5432] + [File Shares]
Bab 15 • Standar Industri

10 Rekomendasi Praktik Terbaik (Best Practices)

05 // HARDENING
01

Terapkan Prinsip Default Deny

Seluruh paket yang tidak diizinkan secara eksplisit wajib ditolak/dibuang. Jangan pernah memakai filosofi open-by-default.

02

Prinsip Hak Istimewa Terendah (Least Privilege)

Hanya izinkan akses ke host, IP spesifik, dan port yang benar-benar mutlak dibutuhkan proses operasional bisnis.

03

Minimalkan Permukaan Port Terbuka

Segera matikan service yang tidak terpakai dan tutup port terkait untuk mempersempit area sasaran eksploitasi peretas.

04

Urutan Aturan Terstruktur (Rule Ordering)

Tempatkan aturan paling spesifik (IP tunggal) di bagian atas dan aturan tangkapan umum di paling bawah.

05

Wajibkan Sentralisasi Log (SIEM)

Kirimkan berkas log firewall ke syslog terpusat agar riwayat bukti forensik tidak dapat dimusnahkan oleh penyusup.

06

Monitoring & Alarm Port Scanning

Pantau lonjakan paket TCP SYN beruntun dan aktifkan fail2ban atau IDS/IPS untuk auto-block IP pemindai.

07

Pencadangan Konfigurasi Teratur

Selalu cadangkan file rules (/etc/ufw/user.rules) sebelum dan sesudah menerapkan perubahan.

08

Pembaruan Firmware & Kernel Berkala

Terapkan patch keamanan sistem operasi dan appliance untuk menambal celah kerentanan Zero-Day.

09

Uji Coba di Staging Environment

Verifikasi setiap aturan baru di VM penguji sebelum diterapkan di server produksi aktif guna menghindari downtime.

10

Audit Aturan Triwulanan (Periodic Review)

Hapus aturan-aturan sementara (obsolete rules) yang dibuat saat debugging masa lalu.
